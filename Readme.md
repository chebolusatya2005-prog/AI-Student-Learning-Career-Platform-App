# AI Student Learning & Career Success Platform

## 1. Project Overview

The AI Student Learning & Career Success Platform is designed to help students improve their learning and career readiness through data analytics and AI-powered personalized learning assistance.

The platform aims to identify student learning gaps, analyse performance, and provide relevant learning support.

## 2. Project Objectives

- Analyse student learning and performance data.
- Identify student risk levels and learning gaps.
- Understand placement readiness.
- Support personalized learning recommendations using AI.
- Provide useful insights through role-based dashboards.

## 3. Dataset Description

The project dataset contains:

- 500 student records
- 63 columns
- Student learning and performance-related information

The dataset was explored using Python, Pandas and Jupyter Notebook.

## 4. Technologies Used

- Python
- Pandas
- Jupyter Notebook
- MySQL
- SQL
- Statistics
- Exploratory Data Analysis (EDA)
- Google AI Studio
- Supabase

## 5. Exploratory Data Analysis

The Week 1 EDA included:

- Loading student data from MySQL.
- Inspecting dataset structure and data types.
- Generating descriptive statistics.
- Checking duplicate student IDs and duplicate records.
- Analysing student risk distribution.
- Analysing placement readiness.
- Exploring correlations between learning metrics.
- Creating data visualizations.

## 6. Key EDA Findings

| Metric | Result |
|---|---:|
| Total student records | 500 |
| Low-risk students | 248 (49.6%) |
| Medium-risk students | 147 (29.4%) |
| High-risk students | 105 (21%) |
| Placement-ready students | 108 (21.6%) |
| Students still developing | 392 (78.4%) |
| Average readiness score | 61.67 |

## 9. How to Run the EDA Notebook

1. Install Python and Jupyter Notebook.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy pymysql
```

3. Open Jupyter Notebook.
4. Open `EDA.ipynb`.
5. Configure your own MySQL database connection securely.
6. Execute the notebook cells in order.

**Note:** Database credentials should never be committed to GitHub. Use environment variables or another secure configuration method.
